===================================================
FIX 1 — FAVICON (BROWSER TAB ICON)
===================================================
Add or replace the favicon tags in the shared <head> template
that applies to ALL pages. Use these exact tags:

<link rel="icon" type="image/png" href="/assets/images/favicon.png">
<link rel="shortcut icon" href="/assets/images/favicon.png">
<link rel="apple-touch-icon" href="/assets/images/favicon.png">

Rules:
- Must be in the shared head template — not on individual pages
- href must be root-relative (/assets/images/favicon.png)
- Remove any existing favicon link tags before adding these
- If the site currently references a Replit default icon or
  any other favicon path, replace it

Verify: open any page in the browser — the tab should show
the circular GR icon mark (navy ring with orange accent).
